* rev. 15 - 2026 05 12 (v3)

- Vector action history: every stroke is recorded as {brush, color, size, opacity, symmetry, seed, points: [{x,y,p,tx,ty}], settings} instead of a raster snapshot. Typical sessions are KB instead of MB; autosave quota is no longer a concern.
- Deterministic brushes: introduced a seeded mulberry32 PRNG (`_r()`) that all 50+ brushes use in place of `Math.random()`. Each stroke records its seed; replay re-runs the exact RNG stream → pixel-perfect reproduction.
- Save format: `.harmony` files are now JSON (`format: "harmony-v3"`), not SVG-wrapping a PNG. Open from v3 → restores full action history (granular undo / GIF export / future-proof).
- Undo / redo: `HISTORY_MAX` raised from 30 to 1000. Undo rewinds the action index and re-replays the canvas; brush state (sketchy connecting lines etc.) is properly reset.
- GIF export reads from the action log instead of the raster history — same one frame per stroke, but no raster history needed.
- Removed the "Lossless (PNG)" toggle in the overflow menu; vector replay is always lossless.
- Tests: `node v3/smoke-test.js` extends v2's brush-settings consistency checks with v3 determinism, seed-sensitivity, brush op-stream replay equality (splatter / sketchy / stipple / crayon / watercolor / chalk / circles), .harmony JSON round-trip, and an eraser→simple composite-op leak guard.
