Harmony procedural drawing — forks & successors

Mr.doob's Harmony and its generative, neighbour-aware brushes (sketchy, chrome, fur, web, …). For the classic experience, use Mr.doob's original v1 — it's still the most recommended. For a full-featured tool built for newer, more capable hardware — layers, real pen-pressure, a smarter memory map — try Nekudot, a from-scratch reimagining. v2 is our modern UI rebuild; v3 is an experimental vector-format prototype.

v2 — Modern UI

A full UI rebuild on top of v1's brush model. Current stable build.

  • 50+ brushes across 5 families — classic, geometric, atmospheric, studio, tools
  • Floating glass toolbar, brush-tile picker, custom modal, mobile bottom-sheets, auto dark mode
  • Pointer Events with Apple Pencil pressure + tilt, multi-finger gestures (2-finger undo, 3-finger redo, pinch-zoom)
  • Per-brush settings panel, symmetry guides, hold-⇧ straight lines, eyedropper
  • Canvas autosaved to IndexedDB; .harmony SVG-wrapped PNG download with embedded undo history
  • GIF export from a rolling stroke recorder

v3 — Vector format

v2 rebuilt around an action log. The canvas is just a render of the log.

Experimental — not for use. Vector replay diverges from live drawing for a few stateful brushes; performance degrades on 100k-stroke logs. A prototype for the format only — use v1 or Nekudot for real work.
  • Vector save format — .harmony files are now a JSON action log (brush + color + pressure + tilt + seeded RNG state per stroke). Sessions go from MB to KB.
  • Pixel-deterministic replay — every brush uses a per-stroke mulberry32 seed instead of Math.random(). Same seed → identical canvas.
  • Gzipped on download (CompressionStream); upload auto-detects via magic bytes.
  • Strokes panel (s) — list every stroke, click to highlight on canvas, edit color / size / opacity / brush, delete, live preview, animated GIF export.
  • 1000-stroke undo, replay-based GIF export from the action log, no more raster history.

Nekudot

A from-scratch successor — the neighbour-line drawing idea rebuilt as a full tool for modern hardware. Recommended when you want more than the classic.

  • Layers — compose, reorder, blend, lock; not a single flat canvas
  • Real pen-pressure support — pressure, tilt and velocity drive every brush
  • Advanced memory map — tiled canvas storage that scales to large, long sessions
  • Designed for newer, more capable devices — high-DPI, stylus, GPU-accelerated
  • Built from the ground up rather than forked from the 2010 source

Benchmark — 5 000-stroke cityscape

A deterministic 5 000-stroke cityscape (sky → sun → mountains → buildings → windows → street → foliage → birds → stars) used to compare v3's vector format against raster formats. The image below is the final state, rendered through v3's actual brushes (using the saved .harmony file in v3/).

What you're looking at

10 phases of 500 strokes each, painted in order: watercolor sky wash, simple-line sun rays, sketchy distant mountains, simple-line building silhouettes, mid-distance buildings + watercolor color wash, stipple windows, calligraphy road strokes, simple-line foliage clusters, simple-line birds & people, and stipple stars.

The PNG was produced by replaying v3/benchmark-5000.harmony through v3's own brush prototypes — running the open-file path on the saved vector log produces this exact image, pixel for pixel (modulo PNG quantization).
